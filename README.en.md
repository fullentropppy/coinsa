**Coinsa** is an iOS app for tracking expenses while traveling. It helps you plan expenses, track spending by location, and get insights into your budget and spending.

## Main Features

### Trips and Locations
- Create trips with a primary currency (all budgets and expenses are stored, entered, and displayed in this currency)
- Add locations within each trip with a local currency (amounts can be entered and displayed in both the local and primary currencies)

### Budget and Expenses
- Plan a budget for each location by subcategory and category:
  - Food
  - Transport
  - Accommodation
  - Leisure
  - Shopping
  - Mediсine
  - Miscellaneous
- Track expenses by these categories at each location, including the payment method:
  - Cash
  - Card
- Store and view the location where an expense was made

### Currencies and Exchange Rates
- Automatically load up-to-date exchange rates
- Choose a currency from the list for each individual expense
- Set an exchange-rate adjustment percentage, for example to account for a bank fee

### Analytics
- Simple and clear analytics for each trip and location:
  - Total budget and expenses
  - Average daily budget and spending
  - Number of expenses and the largest expense
  - Expenses by day as a chart and list
  - Expenses by category and subcategory as a chart and list

### "Today" Screen
- Information for the current day:
  - Recommended budget for today
  - Actual spending for the day
  - Remaining recommended budget
  - Current exchange rate for the location's currency
- Quick access to create a new expense
- List of today's expenses

### Synchronization
- **Automatic data synchronization through iCloud** — all app data is available across your Apple devices.
