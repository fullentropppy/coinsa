**Coinsa** - iOS-приложение для отслеживания расходов в путешествиях. Помогает планировать расходы, учитывать траты на локациях и получать аналитику по бюджету и тратам.

## Основные возможности

### Управление поездками и локациями
- Создание поездок с выбором основной валюты (в ней хранятся все бюджеты и траты, вводятся и отображаются суммы)
- Добавление локаций внутри каждой поездки c выбором местной валюты (в ней, как и в основной валюте, вводятся и отображаются суммы)

### Бюджет и траты
- Планирование бюджета для каждой локации по подкатегориям и категориям:
  - Еда
  - Транспорт
  - Проживание
  - Отдых
  - Шоппинг
  - Медицина
  - Прочее
- Учёт трат по этим категориям на локациях, с указанием способа оплаты:
  - Наличные
  - Карта
- Хранение и просмотр геолокации места траты

### Валюты и курсы
- Автоматическая загрузка актуальных курсов валют
- Возможность выбора валюты из списка в каждой отдельной трате
- Возможность задать процент корректировки курса (например, для учёта комиссии банка)

### Аналитика
- Простая и наглядная аналитика по каждой поездке и локации:
  - Общий бюджет и траты
  - Бюджет и траты в среднем в день
  - Количество трат и самая крупная трата
  - Траты по дням в виде графика и списка
  - Траты по категориям и подкатегориям в виде диаграммы и списка

### Экран «Сегодня»
- Информация по текущему дню:
  - Рекомендованный бюджет на сегодня
  - Фактические траты за день
  - Остаток рекомендованного бюджета
  - Актуальный курс валюты локации
- Быстрый доступ к созданию новой траты
- Список трат за сегодня

### Синхронизация
- **Автоматическая синхронизация данных через iCloud** — все данные приложения доступны на ваших устройствах Apple.
