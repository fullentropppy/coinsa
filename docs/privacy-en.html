Privacy Policy

App: Coinsa
Effective date: September 2026
Last updated: November 28, 2026

This Privacy Policy describes how Coinsa ("the App") handles user data.

1. Data Collection

The App is designed to minimize data collection.

Coinsa does not require account registration or ask for the user’s name, email address, or phone number.

Trips, locations, budgets, and expenses, including general trip expenses, comments, dates, time zone information, and saved coordinates, are stored locally on the device and synced through the user’s private iCloud storage when available. App settings, selected converter currencies, and the converter amount are stored locally on the device.

With the user’s permission, the App may request the device’s current location to save an expense location. Automatic location detection when creating an expense can be disabled in the App settings; the location can also be selected on a map or cleared. The App does not request continuous background location tracking. Saved coordinates are not sent in exchange-rate or version-check requests.

2. iCloud (CloudKit)

The App uses Apple CloudKit to store and sync user data.

Synced records are stored in the user’s private iCloud database associated with their Apple Account. Data processing by iCloud is governed by Apple’s Privacy Policy.

The developer of the App does not have access to this data.

3. Third-Party Services

The App uses Hexarate to retrieve currency exchange rates. Requests include the currency codes for the requested pair.

To check for a new version and retrieve release notes, the App contacts the developer’s API hosted on Cloudflare. The request header includes the installed App version and build number.

Trips, locations, expenses, and saved expense locations are not sent to the exchange-rate service or the version-check API.

The App uses MapKit and Apple’s mapping services to display and select expense locations and show analytics maps. When loading maps, Apple receives information about the viewed area and technical request information. This processing is described in Apple Maps & Privacy.

When the App contacts external services, their infrastructure receives the connection’s IP address and technical request information. Cloudflare processes this information in accordance with its Privacy Policy.

4. Data Usage

The App uses user data for:

- Tracking trip expenses
- Calculating budgets and analytics
- Displaying currency conversions
- Displaying and selecting expense locations on maps
- Exporting and importing records at the user’s request

5. Data Sharing

The App does not sell or rent user data. iCloud is used for storage and synchronization as described in section 2. When retrieving exchange rates, loading maps, and checking the version, the App shares the information described in section 3 with external services.

At the user’s request, the App exports all trips, locations, and expenses to a plain JSON file. It includes budgets, amounts, currencies, rates, payment methods, categories, comments, dates, time zone information, and saved coordinates with their recorded accuracy. App settings are not included.

The user chooses where to save the file in a system dialog. If iCloud Drive or another cloud file service is selected, that service processes the file under its own terms. The App does not send the export to the developer. Import reads a file selected by the user and merges records with the App’s data; imported records may then sync through iCloud.

The App does not use advertising or tracking technologies.

6. Data Security

Data stored in iCloud is protected by Apple’s security infrastructure. Local records are kept in the App’s storage using iOS protection mechanisms.

The App does not encrypt exported JSON files. Anyone with access to a file can read its contents. Protection of a saved copy depends on the chosen storage location and the access granted to it.

7. User Control

Users have full control over their data. Data can be deleted at any time within the App.

Location access can be changed in iOS system settings. Disabling access or automatic location detection does not delete previously saved coordinates; they can be cleared in the expense editor.

Removing the App will remove local data. iCloud data can be managed through Apple ID settings.

Deleting records or removing the App does not delete previously exported files. The user manages these separately in the chosen storage location. Importing a previously saved file may add records that were deleted in the App again.
