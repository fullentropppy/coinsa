Политика конфиденциальности

Приложение: Coinsa
Дата вступления в силу: Сентябрь 2026

Настоящая Политика конфиденциальности описывает, как Coinsa («Приложение») обрабатывает данные пользователей.

1. Сбор данных

Приложение разработано с целью минимизации сбора данных.

Coinsa не требует регистрации учетной записи и не собирает персональные данные, позволяющие идентифицировать пользователя, такие как имя, адрес электронной почты или номер телефона.

Все данные, введенные пользователем (например, поездки, местоположения и расходы), хранятся локально на устройстве и, при необходимости, в личном хранилище iCloud пользователя. При создании расхода Приложение может использовать текущее местоположение устройства для сохранения места совершения этого расхода. Сохраненное местоположение используется только внутри Приложения для отображения места, где был совершен расход, и не передается разработчику или сторонним сервисам.

2. iCloud (CloudKit)

Приложение использует Apple CloudKit для хранения и синхронизации данных пользователя.

Все данные хранятся в личной базе данных iCloud пользователя и связаны только с его Apple ID.

Разработчик Приложения не имеет доступа к этим данным.

3. Сторонние сервисы

Приложение использует сторонний сервис для получения курсов валют.

Запросы, отправляемые этому сервису, не содержат персональных данных и ограничиваются технической информацией, такой как валютные пары.

4. Использование данных

Данные пользователя используются исключительно внутри Приложения для:

- Учета расходов в поездках
- Расчета бюджетов и аналитики
- Отображения конвертации валют
- Отображения места совершения расхода с использованием сохраненного местоположения

5. Передача данных

Приложение не продает, не сдает в аренду и не передает данные пользователя третьим лицам.

Приложение не использует рекламные технологии или технологии отслеживания.

6. Безопасность данных

Данные, хранящиеся в iCloud, защищены инфраструктурой безопасности Apple. Локальные данные безопасно хранятся на устройстве пользователя.

7. Контроль пользователя

Пользователь имеет полный контроль над своими данными. Данные можно удалить в любое время внутри Приложения.

Удаление Приложения удалит локальные данные. Данными в iCloud можно управлять через настройки Apple ID.

8. Изменения в настоящей Политике

Настоящая Политика конфиденциальности может быть обновлена в будущем. Все изменения будут отражены на этой странице.
