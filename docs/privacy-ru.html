Политика конфиденциальности

Приложение: Coinsa
Дата вступления в силу: Сентябрь 2026
Дата обновления: 28 ноября 2026

Настоящая Политика конфиденциальности описывает, как Coinsa («Приложение») обрабатывает данные пользователей.

1. Сбор данных

Приложение разработано с целью минимизации сбора данных.

Coinsa не требует регистрации учетной записи и не запрашивает имя, адрес электронной почты или номер телефона пользователя.

Поездки, локации, бюджеты и траты, включая общие траты поездки, комментарии, даты, сведения о часовом поясе и сохраненные координаты, хранятся локально на устройстве и синхронизируются через личное хранилище iCloud пользователя, когда оно доступно. Настройки Приложения, выбранные валюты и сумма конвертера хранятся локально на устройстве.

С разрешения пользователя Приложение может запрашивать текущее местоположение устройства для сохранения места траты. Автоматическое определение места при создании траты можно отключить в настройках Приложения; место также можно выбрать на карте или очистить. Приложение не запрашивает постоянное отслеживание местоположения в фоне. Сохраненные координаты не отправляются в запросах курсов валют и проверки версии.

2. iCloud (CloudKit)

Приложение использует Apple CloudKit для хранения и синхронизации данных пользователя.

Синхронизируемые записи хранятся в личной базе данных iCloud пользователя, связанной с его учетной записью Apple. Обработка данных сервисом iCloud регулируется политикой конфиденциальности Apple.

Разработчик Приложения не имеет доступа к этим данным.

3. Сторонние сервисы

Приложение использует сервис Hexarate для получения курсов валют. В запросах передаются коды валют запрашиваемой пары.

Для проверки наличия новой версии и получения описания изменений Приложение обращается к API разработчика, размещенному на Cloudflare. В заголовке запроса передаются установленная версия Приложения и номер сборки.

Поездки, локации, траты и сохраненные места трат не отправляются сервису курсов валют или API проверки версии.

Для отображения и выбора мест трат, а также карт аналитики Приложение использует MapKit и картографические сервисы Apple. При загрузке карт Apple получает сведения о просматриваемой области и технические сведения о запросах. Обработка этих сведений описана в документе Apple Maps и конфиденциальность.

При обращении к внешним сервисам их инфраструктура получает IP-адрес подключения и технические сведения о запросе. Cloudflare обрабатывает эти сведения в соответствии со своей политикой конфиденциальности.

4. Использование данных

Приложение использует данные пользователя для:

- Учета трат в поездках
- Расчета бюджетов и аналитики
- Отображения конвертации валют
- Отображения и выбора мест трат на картах
- Экспорта и импорта записей по действию пользователя

5. Передача данных

Приложение не продает и не сдает в аренду данные пользователя. Для хранения и синхронизации используется iCloud, как описано в разделе 2. При получении курсов валют, загрузке карт и проверке версии внешним сервисам передаются сведения, описанные в разделе 3.

По действию пользователя Приложение экспортирует все поездки, локации и траты в обычный JSON-файл. Он включает бюджеты, суммы, валюты, курсы, способы оплаты, категории, комментарии, даты, сведения о часовом поясе и сохраненные координаты с точностью их определения. Настройки Приложения в файл не входят.

Место сохранения выбирает пользователь в системном диалоге. Если выбран iCloud Drive или другой облачный файловый сервис, файл обрабатывается этим сервисом по его условиям. Приложение не отправляет экспорт разработчику. Импорт читает выбранный пользователем файл и объединяет записи с данными Приложения; импортированные записи могут затем синхронизироваться через iCloud.

Приложение не использует рекламные технологии или технологии отслеживания.

6. Безопасность данных

Данные, хранящиеся в iCloud, защищены инфраструктурой безопасности Apple. Локальные записи хранятся в хранилище Приложения с использованием механизмов защиты iOS.

Экспортируемый JSON-файл не шифруется Приложением. Любой, кто получит доступ к файлу, сможет прочитать его содержимое. Защита сохраненной копии зависит от выбранного места хранения и предоставленного к ней доступа.

7. Контроль пользователя

Пользователь имеет полный контроль над своими данными. Данные можно удалить в любое время внутри Приложения.

Доступ к геопозиции можно изменить в системных настройках iOS. Отключение доступа или автоматического определения места не удаляет ранее сохраненные координаты; их можно очистить в редакторе траты.

Удаление Приложения удалит локальные данные. Данными в iCloud можно управлять через настройки Apple ID.

Удаление записей или Приложения не удаляет ранее экспортированные файлы. Пользователь управляет ими отдельно в выбранном месте хранения. Импорт ранее сохраненного файла может заново добавить записи, удаленные в Приложении.

8. Изменения в настоящей Политике

Настоящая Политика конфиденциальности может быть обновлена в будущем. Все изменения будут отражены на этой странице.
