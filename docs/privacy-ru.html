Политика конфиденциальности

Приложение: Coinsa
Дата вступления в силу: Сентябрь 2026
Дата обновления: 21 ноября 2026

Настоящая Политика конфиденциальности описывает, как Coinsa («Приложение») обрабатывает данные пользователей.

1. Сбор данных

Приложение разработано с целью минимизации сбора данных.

Coinsa не требует регистрации учетной записи и не запрашивает имя, адрес электронной почты или номер телефона пользователя.

Все данные, введенные пользователем (например, поездки, локации, траты, местоположение трат), хранятся локально на устройстве и, при необходимости, в личном хранилище iCloud пользователя. При создании траты Приложение может использовать текущее местоположение устройства для сохранения места совершения этой траты. Сохраненное местоположение используется внутри Приложения для отображения места, где была совершена трата, и не отправляется в запросах курсов валют и проверки версии.

2. iCloud (CloudKit)

Приложение использует Apple CloudKit для хранения и синхронизации данных пользователя.

Все данные хранятся в личной базе данных iCloud пользователя и связаны только с его Apple ID.

Разработчик Приложения не имеет доступа к этим данным.

3. Сторонние сервисы

Приложение использует сервис Hexarate для получения курсов валют. В запросах передаются коды валют запрашиваемой пары.

Для проверки наличия новой версии и получения описания изменений Приложение обращается к API разработчика, размещенному на Cloudflare. В заголовке запроса передаются установленная версия Приложения и номер сборки.

Поездки, локации, траты и сохраненные места трат не отправляются сервису курсов валют или API проверки версии.

При обращении к внешним сервисам их инфраструктура получает IP-адрес подключения и технические сведения о запросе. Cloudflare обрабатывает эти сведения в соответствии со своей политикой конфиденциальности.

4. Использование данных

Данные пользователя используются исключительно внутри Приложения для:

- Учета трат в поездках
- Расчета бюджетов и аналитики
- Отображения конвертации валют
- Отображения места совершения траты с использованием сохраненного местоположения

5. Передача данных

Приложение не продает и не сдает в аренду данные пользователя. Для хранения и синхронизации используется iCloud, как описано в разделе 2. При получении курсов валют и проверке версии внешним сервисам передаются технические сведения, описанные в разделе 3.

Приложение не использует рекламные технологии или технологии отслеживания.

6. Безопасность данных

Данные, хранящиеся в iCloud, защищены инфраструктурой безопасности Apple. Локальные данные безопасно хранятся на устройстве пользователя.

7. Контроль пользователя

Пользователь имеет полный контроль над своими данными. Данные можно удалить в любое время внутри Приложения.

Удаление Приложения удалит локальные данные. Данными в iCloud можно управлять через настройки Apple ID.

8. Изменения в настоящей Политике

Настоящая Политика конфиденциальности может быть обновлена в будущем. Все изменения будут отражены на этой странице.
